## INSTALLING
- Open SFTp and go inside /var/www/pterodactyl
- Drag and drop the **kts-host-vX.zip**.
- unzip kts-host-v1.zip -d kts-host-installer
- cd kts-host-installer
- sudo bash install.sh

## UPDATING
- Upload the new **kts-host-vX.zip** into /var/www/pterodactyl (or beside update.sh).
- unzip kts-host-vX.zip -d kts-host-installer
- cd kts-host-installer
- sudo bash update.sh
- Pick the zip from the list.
